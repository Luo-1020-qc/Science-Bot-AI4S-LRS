# 详细工具契约库

由export_catalog.py生成。每个工具的状态是契约的一部分；未实现或真实执行工具不能调用。

状态：offline_implemented=本目录可运行；existing_*=已有受限入口或复用数学检查；contract_only=仅设计；human_review_required=待人工流程；disabled_real_execution=本库禁用。

## tool_catalog

查看工具输入输出、状态、权限与后续步骤

分组：`discovery`；状态：`offline_implemented`。

前置条件：无

验收：清楚区分已实现、已有入口与待实现契约

权限/作用：local_mock_only; never grants real execution；sandbox_artifacts_only

幂等：Content-addressed immutable outputs; mock job key is frozen-plan identity

失败处理：Invalid schema or stale artifact: fail before action; do not silently default

输入：

```json
{
  "type": "object",
  "properties": {},
  "required": [],
  "additionalProperties": false
}
```

输出：

```json
{
  "type": "object",
  "properties": {
    "tools": {
      "type": "array",
      "items": {},
      "minItems": 0,
      "maxItems": 1000
    },
    "live_agent_registered": {
      "type": "boolean"
    }
  },
  "required": [
    "tools",
    "live_agent_registered"
  ],
  "additionalProperties": false
}
```
