# 合成依据、修订理由和研究边界

本批由 LLM 协助设计并由确定性代码生成，以原始 source_A 合成模板为祖先。新增独立科学来源为 0，人工专家标签为 0。它用来训练并检查有限候选动作的决策策略，不是现实科学结论的证据。

## 修订依据

- 原批次有 3 条交互任务功效未通过，并且当前候选动作不能修订布局。新版不覆盖该检查，也不更改 verifier；使用提前声明的不同合成模型，清楚列出参数。原批次仍保留，不能将新版说成是对原实际数据的拟合或补救。
- 原 OOM 任务同时设置已有作业，使失败分支被复用绕过。新版所有新作业 OOM 均设置 existing_job=false；已有作业复用与 OOM 分别作为不同场景。
- 无证据停止、未知工具、遗漏随机化等纯文字要求没有当前环境机制支持，已从本批训练承诺移除。当前只接受公开方差不可获得或实际 mock 失败作为停止证据。
- 50 个任务按公开实验设计要求和后续反馈机制组成不同的组合；没有用新来源 ID 包装模板复用，没有把共享祖先拆到独立评价集。

## 合成 DOE 参数

声明 Gaussian、同方差、固定效应等模板假设，sigma=0.02。主要效应 minimum_effect=0.03；交互作用的差中差 minimum_effect=0.05；实际意义阈值均为 0.01。后两者的含义分别是规划可检测效应与实际意义阈值，不能混用。数值只为构造一个透明、可检查的前瞻合成环境，不具有经验估计来源。

主要效应与交互作用的对比尺度不同。当前固定模板通常为 48 次运行，交互差中差具有更大的方差因子。所有已知方差任务均通过原 G2.4 verifier 的功效、估计性、预算与随机化检查；不能据此声称真实单位独立性、方差或随机化已经被验证。

方差不可获得的六个任务不参与冻结/功效合格声明，必须先提问并取得用户不可提供的证据。模板内部初始化值不是科学证据，宿主仍阻止复核和冻结。

## 单位与因素

Darcy：模拟中独立分配的预测器应用/数据实现作为处理应用单位；因子设计第二因素为 resolution。CViT：一次独立随机种子模拟训练运行作为处理应用单位；因子设计第二因素为 learning_rate。区组设计声明数据实现区组；CRD 不借用区组表述。

这些定义是教学模型的声明，真实研究中需要分别核实共享数据、共享种子、重复测量、训练重复、分配单位与推断单位，不能将网格点数量或技术重复当作独立样本量。

## 待专家解决的争议

1. effect、sigma 与模型假设在真实 Darcy/CViT 上是否合理，需要独立先导观测和领域评审。
2. 新版仍复用当前固定模板与数学，不支持混合效应、复杂缺失、真实非劣检验或任意实验设计。
3. 32 维状态投影有信息损失；50 个结构配置只有 36 种初始 Actor 向量。不能用提示词复杂度夸大学习难度。
4. action mask、候选参数绑定和 verifier 已承担一部分规划责任；训练成功不能归因于模型学会了全部 DOE。
5. 当前终局 +10 同时用于完整闭环与有证据停止，属于明确的协议选择；真实开放环境还应审阅证据是否被策略投机制造。
6. BC 参考由规则策略产生；PPO 的训练集成功不能证明它超越规则或产生新科学方法。需要独立来源和消融来支持该论断。

## 专家后续扩展的最小要求

保留合成/真实来源区分，给出单位、因素、主要对比、方差/效应依据、可接受替代步骤和反例。新增机制必须先进入环境、观察、候选动作和验收器，再出现在训练场景承诺中。当前 source_A 的任何派生任务都不得进入声称独立的评价集。
