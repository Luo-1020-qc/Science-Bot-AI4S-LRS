# 详细工具库接入记录

用户授权将详细工具库整体接入Harness，以便下一步训练。本轮接入20个已实现离线工具；其余契约状态保持原样，真实执行禁用。

- 改动四个既有宿主文件：工具注册表、路由、会话、终端。新增会话适配器及隔离worker。
- 原core.py、catalog.py、doe_adapter.py和v2训练副本未修改；旧权重、数据和冻结研究继续核验。
- 新会话工具预算40；旧会话不自动提额。在线规划通过原模型Provider，手动／训练调用无需模型API。
- 同会话制品、模型引用校验、幂等、预算、旧复核处理、工作流核验和模拟情景宿主绑定均进入实际执行路径。
- 本轮不重训、不推广默认策略、不发起真实模型API请求或科研作业。

原清理保护基线保持不动。`authorized_source_changes.json`记录用户授权的四处宿主接线改动及原／新哈希，`runtime_manifest.json`固定本轮执行器源码，当前完整性检查叠加这些记录；不将改动伪装成原文件未变。

使用方法现统一见[使用说明](../../USAGE.md)，最终结果见[verification.json](verification.json)。原始清理验收说明的是接入前版本，不等于今天整个宿主源码一字未改。
