# 边界问答工具接入 · 2026-10-29

新增注册的只读 `question_tool`，通过原终端/浏览器/HTTP的 `/plan question` 命令启用。逐项选择未明确边界，保留模板路径，可显式选择合成训练的排序候选。问题不授予执行权限，回答仍经原语义整理、版本账本及确认失效机制。操作说明见[规划指南](../../HARNESS_PLANNING.md)，实际训练与局限见[训练记录](../../../RUT_Science/research/question_tool_v1/README.md)。

## 验证范围

新工具测试覆盖注册契约、只读与候选限制、冲突/过期优先、未知和证据获取、权重异常回退、重复问题复用、模型措辞保留、原回答入口、轨迹完整性、脱敏导出、预算、确认失效、跨进程恢复及原HTTP消息入口。完整性测试另外检查候选权重、旧研究权重和历史收据的保护边界。

实际全量结果为444项应用测试，0失败/错误、2跳过，22项完整性测试通过；训练权重和完整轨迹独立重算一致，64个状态经实际工具只读边界检查。原1745个保护文件、64个旧训练制品、21份此前集成JSON保持一致。

新增授权层只覆盖注册、规划调用和包资源元数据，以及新工具/排序器/候选共6个运行文件；7个新训练源和制品另有清单。改动前快照固定此前所有集成JSON和模型提供者；不重写旧源清单、427项界面回归或已有科学评估结果。

`full_tests.json` 是当前层全量应用和完整性测试的实际收据；`verification.json` 对照源码与清单，独立重算训练权重、64个留出任务的完整轨迹，并用实际注册工具检查64个状态。默认审计不会发模型请求、运行真实实验或覆盖训练制品。

