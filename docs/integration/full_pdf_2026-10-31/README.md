# PDF全文读取与任务额度配置

本层承接计划合成版本，修复原入口只能选择12页/18000字节以及论文解读、计划合成共用1800输出token的限制。旧集成清单、失败记录、数据和权重保留原字节；provider的任务额度调整由本层单独授权并串联前版本哈希。

## 使用

重启服务，**新建研究**，用 `-Workspace` 绑定论文所在目录。在证据材料页输入PDF相对路径，两个页码留空表示读取整篇；仍可指定连续物理页码。页面颜色、字体、排版及原HTML/CSS保持不变，现有表单只更新提示和提交行为。

```text
/plan evidence add {"path":"papers/paper.pdf","share_with_model":true}
/plan evidence list
/plan evidence understand <证据编号>
/plan synthesize
/plan draft
```

`share_with_model` 默认为false。省略页码只表示完整的本地提取，明确共享并点击“让LLM理解所选页”才会发出模型请求。`start_page` 可单独指定，表示从该页到末页；同时指定起止页则只读所选范围。

## 全文与模型上下文

- 文字型PDF最多64 MiB、256个所选物理页、2 MiB提取文字。隔离解析超时90秒；页级解压保护保留。超过保护值明确拒绝，不静默截断。
- 页码、完整提取文字、文件和片段哈希随规划保存；空白页保留物理编号。扫描/图片页需要OCR，公式、图表、分栏顺序不能据文字提取认定已理解。
- 每次解读最多8个页面片段、24000个UTF-8正文字节。超长单页按字符拆分，拼接可恢复完整原文，不丢字符。全部批次按顺序处理，页码引用逐项校验。
- 分批结果记录批次哈希与完成数量。后续批次失败时明确显示部分完成；再次点击继续未完成批次，已完成批次不重复请求。第一批失败不伪造解读；离线和未共享材料不调用模型。
- “所有批次已处理”表示文本已送入模型处理，不能证明模型理解了每一处含义。模型要点始终待人类复核，未通过引用/数值校验的要点单独拒绝。
- 后续规划使用分批解读中分布于全篇的原文引文选择（最多64条、24000字节），请求中明确标记它是摘录。完整原文和全部解读仍可查看、导出；不会把整篇反复塞进每次追问。长文尚未完成分批阅读时，明确要求先完成阅读。
- 解读变化进入计划来源版本哈希，旧的失败缓存不能掩盖新读完的证据；旧计划需要更新后再确认。

## 额度

| 项目 | 当前设置 |
|---|---|
| 普通对话等单次输出 | 保持1800 token |
| 论文解读、实验计划合成单次输出 | 分别默认8192 token |
| 原生模型请求输入保护 | 含工具Schema的序列化消息最多100000字节；分批不等于无限上下文 |
| 新研究会话预算 | 24次模型请求、300000个累计计账token、40次工具尝试、2 MiB文件读取额度 |

输出额度可在启动服务的PowerShell中配置，实际数值须在模型服务支持的范围内：

```powershell
$env:SCIENCE_BOT_PAPER_OUTPUT_TOKENS = '8192'
$env:SCIENCE_BOT_PLAN_OUTPUT_TOKENS = '8192'
.\science-bot-web.cmd -Workspace .
```

两个环境变量允许1024–32768。它们只控制相应任务的单次输出，不增加原会话的累计预算。模型回复 `finish_reason=length` 时单独识别为输出截断，不再仅报告JSON错误；不采用半份结果，也不自动加额或重试。

真实服务曾在已完整的工具参数JSON后附加一个多余的 `}`。只对论文理解和计划合成的已注册原生函数，在正常结束且移除这一个括号后能通过严格JSON解析时进行规范化，调用记录保存 `removed_one_redundant_final_brace` 标记。缺失闭合、重复键、非有限数值、多个多余括号及其他尾随内容继续拒绝；截断从不修补。普通对话、命令解析和其他工具不采用此兼容处理。

计划文献引文允许纯空白对齐，并保存原文实际子串；还必须同时存在于模型得到的摘录和本地完整证据中，防止拼接不连续摘录冒充原文。此调整不改变事实、数值和方法检查。

旧会话恢复时保留原预算，避免悄悄扩大已授权消耗。要使用新的全文默认额度，请在重启服务后新建研究。分批处理可能产生多次请求；`/status` 可查看实际消耗。任意长度论文仍可能需要增加明确预算或分段处理。

## 验证与限制

定向检查使用31页合成PDF（重复既有两页工程样例），覆盖大于旧文本限制的全文、末页、空白页、超长中文页面无损拆分、失败续读、隐私、恢复和导出，以及解读后的计划生成。它不是独立科研质量评估。

真实接口已完成31页的4批处理，得到28条有原文依据的解读，1条未通过要点校验而拒绝；模型未为第31页单独产出要点，但该页正文在最后批次中发送，不能据此宣称每页都有完整语义解释。首次计划因引文换行未对齐被拒绝；修改后复用阅读结果，以一次明确的新请求得到含论文引用、3个具体步骤的有效初稿。整个开发过程含前期失败共9次请求、31828个计账token，无自动重试。

当前结果见 [tests.json](tests.json)、[verification.json](verification.json)；真实接口开发检查与失败诊断见 [development_results.json](development_results.json)。首次全量回归暴露普通文件工具不接受新的大额全文读取预算，已把该工具每回合上下文限制在原有合法范围；失败回执保留于 [initial_regression.json](development/initial_regression.json)。没有读取未选择的真实论文，没有科研执行或模型训练，没有完成独立专家语义评价。模拟DOM检查不等同于完整浏览器视觉验收。
