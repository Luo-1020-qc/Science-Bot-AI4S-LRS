# 科研规划可靠性与复核提示

用户授权交付三项能力：可靠的规划入口、明确的回答与更正反馈、可信的复核提示，并保持现有页面风格与排版。此版本在原 Harness 上实现，不替换默认问题策略、不开展 LLM 微调，不接入真实科学训练。

工作开始于2026-10-30，最终验收完成于2026-10-31；目录名保留首次快照日期。

## 三项交付

| 交付 | 当前行为 |
|---|---|
| 规划入口 | 识别“实验计划”“研究方案”等自然表达；活动规划中的预测、训练/验证划分和代码配置讨论继续进入同一账本。显式文件读取、执行、旧 CSV 访谈及其他命令保留各自入口。 |
| 更新反馈 | 对话使用现有消息气泡显示已采纳、待确认提议、保留未知、冲突及未采纳；更正显示旧值到新值。短回答“是”、选项确认及拟议取证步骤也有回执。 |
| 复核提示 | 分开显示声明完整性与方法待人审状态；识别并阻断本次覆盖的否定匹配关系、技术重复、测试集调参、模板功效保证和隐瞒阴性/追逐显著性反例。没有风险命中也不标记科学有效性已验证。 |

模型改写的研究问题仍须用户确认，普通补充不会自动替换已有问题。完整字段输入中已明确指定的研究问题优先保留。叙述前缀如“实验计划：……”与更正前缀“更正：……”不再一律当作非法字段；混入未知结构化字段的输入仍拒绝。

## 更正与版本保护

能从明确预算更正中逐字定位的新上限，可由宿主记录为用户声明。例如：

```text
更正：后续最多两次运行、一小时上限，之前六次运行的说法作废。
```

不清楚的新值或未通过校验的更正保留旧声明，同时记录 `pending_revisions`、撤销旧确认并阻断继续确认；界面显示未采纳原因。恢复会话后阻断仍存在。泛化的“确认旧提议”不能清除未写入的更正；需明确提供或选择该字段的新决定。

`last_update` 只保留当前回执，完整修改和原话仍在不可变快照/决策记录中。两个扩展为空时保留旧 v1 内容哈希。未知和获取证据的拟议步骤继续分开，不把取证计划写成样本、方差或实测结果。

## 方法复核的含义

复核输出增加 `declarations_complete`、`method_risks`、`method_review_status`。识别到的风险参与阻断，并显示在原有问题列表、研究计划与导出中；同一字段的多个风险分别保留。

“声明齐全”表示具备讨论材料，“方法待人工复核”表示独立性、来源、统计及领域假设尚未得到科学验证。规划确认依旧只确认内容版本；`scientific_claim_verified` 和 `execution_authorized` 始终为 false。此版本的检查是有界规则与跨字段声明核查，不是通用科学审稿或自然语言矛盾识别器。

## 界面保持范围

工作台 `index.html`、`styles.css`、三份静态示例共五个文件与修改前逐字节一致，交付 HTML 的内联 CSS 也保持一致。颜色、字体、图标、页面结构及样式类不变；JavaScript 仅在现有消息气泡和提示区域展示反馈与状态文字。上述约束纳入校验，未生成替代页面或重绘静态预览。
