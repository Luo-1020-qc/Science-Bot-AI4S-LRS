# G2.3 策略强化：独立模拟训练交付

本轮仅新增 `G2_3_Test_Workspace/`，不修改现有 science Bot、G2.2测试工作区、原数据、模型、配置及启动入口。实验配置标记日期为2026-10-26，所有输出留在本目录。

**已完成实际决策策略训练与审计，但没有证明PPO优于规则或匹配基线，不部署到现有Agent。**CViT只在本目录的 `cvit_mock/` 中测试配置与作业协议，没有读取真实CViT数据、导入训练代码、训练CViT权重或启动GPU作业。

## 本轮交付

- 小型CPU决策网络：共享状态编码、动作mask、actor与critic，共23,464个参数；不是LLM或CViT网络。
- 实际BC、BC＋PPO、从零PPO训练，三个固定种子21/37/59。
- PPO包含clipped surrogate objective、terminal-aware GAE、价值损失、熵项、梯度裁剪和Adam更新；设计依据见[PPO原论文](https://arxiv.org/abs/1707.06347)。具体实现是本地简化版，不声称等价于所有成熟训练框架。
- 训练更新边界的模型/优化器/随机状态checkpoint、完整公开特征轨迹、开发选模和最终留出验收。
- CViT配置、预算、内存、确认、已有作业对账、OOM、数据变化与恢复的内存模拟。
- 评分复核、独立修订实验和明确的“不部署”结论，保留负结果。
- 37项独立测试通过；原项目与G2.2目录共37,271个既有文件进行前后完整清单核对。

## 使用

在本文件夹打开PowerShell：

```powershell
& '..\RUT_Science\.venv\Scripts\python.exe' -B run.py demo
& '..\RUT_Science\.venv\Scripts\python.exe' -B run.py test
& '..\RUT_Science\.venv\Scripts\python.exe' -B run.py verify
```

`demo`只演示CViT模拟作业：检查配置 → 形成草案 → 确认 → 对账已有running作业 → 保存/恢复状态 → 获取模拟完成。它复用已有模拟作业，不重复启动；结果的 `metric=null`，不能解释为真实实验误差。

以下命令重核已保存选模/评测，不自动覆盖模型：

```powershell
& '..\RUT_Science\.venv\Scripts\python.exe' -B run.py status
& '..\RUT_Science\.venv\Scripts\python.exe' -B run.py train
& '..\RUT_Science\.venv\Scripts\python.exe' -B run.py evaluate
```

首轮训练在更新边界保存checkpoint；没有最终选模文件时，`train`从相同配置/数据身份的checkpoint恢复。已有最终选模文件时复用，不重新训练。恢复会重算未提交的CPU更新，不会启动外部或GPU作业。

不运行原项目的完整测试或真实工具。借用现有解释器与已安装NumPy/PyTorch，未升级或安装依赖。`-B`阻止外部字节码缓存，缓存目录指向本目录。复制的32个参考文件包括G2.2源码、测试及合成数据，来源和SHA-256在 `evidence/copied_files.json`。

## 首轮固定比较

旧G2.2留出集已经暴露，不再作为新盲测。新封存任务为训练240项（表格128、CViT模拟112）、开发90项（48、42）、最终96项（48、48）。数据身份和根组不重叠，最终测试包含新的机制组合；原始机制仍与训练共享，不宣称全新领域泛化。

所有策略使用相同公开观察、动作权限、预算和96个最终任务。只在开发集上选择BC轮次、PPO更新；PPO比较使用与BC相同的96×96网络结构。BC＋PPO额外使用BC预训练，成本没有混同为从零PPO。BC标签来自脚本参考策略，真实专家标签为0。

| 参数/预算 | 首轮设置 |
|---|---|
| BC | 每种子100轮；仅开发集选择20/40/60/80/100轮之一 |
| PPO | 每种子每算法40次更新，每次512步，共20,480 transitions |
| 正式PPO总量 | 3种子 × 2算法 × 20,480 = 122,880 transitions |
| PPO学习率/epoch | 0.0003 / 每批4轮 |
| clip / gamma / GAE lambda | 0.2 / 0.99 / 0.95 |
| 梯度裁剪 / 熵项 | 0.5 / 0.01 |
| 开发选模 | 成功率优先，再比较阻断尝试与决策数；包括更新0初始策略 |

`evidence/selection_freeze.json`在读取最终任务记录前保存已选模型、任务封存哈希与训练/评测源码哈希。最终集只用于报告，没有根据最终结果重选首轮模型。

## 结果与评分复核

首轮发现CViT模拟的终止奖励可对隐藏的未来拒绝/未知事实给停止奖励，即使策略尚未询问出这些信息。因此原始成功率会高估“正确停止”。原报告完整保留；新增公开证据审计要求停止依据确实存在于当前观察，不重新训练或重选这轮模型。

| 首轮策略 | 原始成功率均值 | 公开证据审计成功率均值 | 审计范围（3种子） |
|---|---:|---:|---:|
| BC | 21.88% | 11.81% | 9.38%–16.67% |
| BC＋PPO | 24.65% | 6.25% | 0%–9.38% |
| 从零PPO | 25.00% | 0% | 0% |
| 上下文规则 | 100% | 100% | 单个确定性规则 |

从零PPO在本轮学成了总是停止的退化策略。不能把平均决策数降低解释为效率提升。首轮每种子有30项具备最终执行资格的模拟任务：规则完成30/30；BC平均完成0.33/30；BC＋PPO与从零PPO均为0/30。

BC＋PPO种子21、59在开发选择中保留了更新0的BC策略；这两个策略虽实际训练了PPO，但选择结果未使用强化后的权重。种子37选了更新40。PPO全部末次训练参数与初始不同，轨迹和checkpoint可核对，未把“保留初始策略”隐去。

最初最终评测只保存回合摘要；为检查公开停止依据，使用同一冻结策略做确定性轨迹回放，逐项核对成功、问题数、决策数、阻断、模拟启动与回报均一致。详见 `evidence/replay_manifest.json`。回放不改变模型，也不是新的独立盲测。

## 独立修订实验

为处理首轮发现的退化，另存 `experiments/feedback_v2/`：

1. 增加参考状态聚合（模仿学习），只在训练任务中用脚本规则标注策略自己遇到的状态，不冒充专家。
2. 反馈奖励要求停止有公开证据；实际完成模拟任务获得较高奖励，无依据停止受到惩罚。
3. PPO加入对选中聚合基线的KL约束，学习率降为0.0001；每种子24×512步。
4. 新增并预先封存48个不同源组/组合的最终任务；先在开发集选定，再读该最终文件。

修订实验额外训练36,864个PPO transitions，总正式训练量为 **159,744**。单元测试中的小批梯度样本另计，不混入正式预算。

| 修订实验 | 种子21 | 种子37 | 种子59 | 均值 |
|---|---:|---:|---:|---:|
| 参考状态聚合基线 | 75.00% | 31.25% | 75.00% | 60.42% |
| 聚合基线＋反馈/KL-PPO | 75.00% | 31.25% | 22.92% | 43.06% |
| 上下文规则 | — | — | — | 100% |

种子21、37保留聚合基线，种子59选择PPO更新24，在新组合上退化。结果不支持PPO替换匹配基线，更不能与首轮不同最终集的百分比直接作提升比较。

修订实验是发现问题后的探索性试验，不能取代首轮固定比较。开发选模仍沿用首轮开发成功率，最终按公开证据严格审计；这个口径差异也是下一版必须统一的限制。现有结果仅支持“训练与反馈机制可运行，并揭示泛化/奖励问题”，不支持科研智能提升的结论。

## CViT隔离测试

专门目录 `cvit_mock/` 包含配置夹具、副本和模拟作业恢复证据。配置为pilot（2轮、4资源单位、4GB声明内存）与full（20轮、8单位、12GB）；这些是协议测试参数，不是测得的真实GPU资源估计。

覆盖：数据/响应/指标/种子缺项、预算与声明内存不足、配置不匹配、拒绝或撤销确认、数据版本变化、已有running/completed任务、任务身份不匹配、模拟OOM、保存/恢复及重复启动拦截。

已有作业的身份和结果来自夹具，不是实际进程或磁盘checkpoint对账。没有真实训练输出、没有L2数值结果、没有读取用户论文/作业数据。所有最终策略的重复模拟启动计数为0；动作mask对权限和作业身份的保护不归功于RL。
